# COURSE.DAT

[← Back to index](index.md)

Every racetrack in the game. Each course has a `.dat` (layout/logic) and `.ps` (polygon/collision mesh) file at the top level, plus a matching `<track>_tims/` folder holding all the scenery, signage, and road-texture `.tim` images used to render that circuit.

**9088** files · **63** subfolders · **5** file types

| Extension | Count | What it is |
|---|---|---|
| `.tim` | 8961 | PlayStation TIM — a raw PS1 image/texture format. |
| `.dat` | 62 | Course layout / game logic data. |
| `.ps` | 62 | Course polygon or collision mesh data. |
| (no ext) | 2 | — |
| `.txt` | 1 | Plain-text index or manifest (GTExplorer metadata, not a game asset). |
