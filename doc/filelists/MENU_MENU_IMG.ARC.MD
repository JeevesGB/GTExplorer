# MENU/MENU_IMG.ARC

**Path:** `MENU/MENU_IMG.ARC`  
**Files:** 41 (40 TIMs + 1 empty)  
**Size:** ~514 KB  
**Format:** GT-ARC (`0x8001`)

## Role

**Background images** for the GT-mode shell menus defined in `MENU_HTM.ARC`. Distinct from the large root `MENU_IMG.ARC` language-pack container.

## Naming

Ordered by `MENU/IMAGES.IDX` (40 names), including:

- UI chrome: `browsbtn.tim`, `cursor.tim`, `refrect.tim`, `shortcut.tim`
- Full-page backgrounds (~153,664 bytes each): `gamemode`, `home`, `map`, `garage`, `gtf`, `toyota`, `trd`, licence/champ/special variants, etc.

## Pairing

Basename match to GTHTML pages, e.g. `HOME.tim` ↔ `home.htm`.

## Note

Do not confuse with disc-root `MENU_IMG.ARC` (~121 MB, six nested language packs).
